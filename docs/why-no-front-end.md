# Why no front end

The operator asks for a usage round, rate check or statement review, and the agent runs the documented command. Reports are read-only HTML in the business brand. They can be printed or shared through the operator's approved process.

A screen provides direct editing, guided data entry, customer self-service and immediate charts. This base provides none of those. It has no mobile capture, drag and drop, live usage feed, hosted ingestion endpoint or offline synchronisation across devices. It reads local exports and recorded usage windows. Enterprise DNA can build a screen and source connections into the business's own version.

This approach suits an internal review desk with a trusted operator. It is not a replacement for a production metering service that must accept billions of events, serve customer dashboards or collect payments. Capacity and access requirements need to be tested on the actual workload before cutover.
